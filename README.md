# 仮想日本人 — Synthetic Survey

仮想日本人パネル（合成・1,000人）にアンケートを投げ、その場で集計する画面です。

**実在の日本人回答者ではありません。** 結果画面には「仮想パネル／合成回答」と表示します。

## ローカルで動かす

```bash
npm install && npm run dev
```

ブラウザで http://localhost:3000 を開きます。

## デモの手順（クリックするだけ）

1. トップの **調査一覧** で「コンビニ弁当購買意向」を確認
2. 右上の **デモを実行** を押す（または行の「実行」）
3. 配信画面で 1,000 人の合成回答が走り、**集計・分析** に進む
4. グラフ・クロス集計・理由テーマ・CSV/JSON を見る

調査をつくる場合:

1. 左メニュー **新規調査作成**（または「編集」）
2. ステッパー **基本情報 → 設問作成 → 対象条件 → 配信設定 → 確認・完了**
3. **仮想パネルに聞く**

## 入っているもの

- 人口加重の仮想パネル 1,000 人（シード固定）
- コンビニ弁当のデモ調査
- 選択 + 短い日本語理由
- ブラウザだけの実行（DB・外部API不要）

## デプロイ（任意）

Vercel ならリポジトリを import して Framework Preset: Next.js のまま Deploy。環境変数は不要です。

プレビューが無い場合は、上記のローカル起動で十分です。

## 対象外

ブラウザ自動操作、実人同等の主張、実査との本学習。
